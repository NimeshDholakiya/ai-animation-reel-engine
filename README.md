## 🧠 The Viral "Retention Connectors" Formula

Short-form videos fail when there is a flat pause between shots. This repository implements the **3-Connector System**:
1. **Verbal / Narrative Connectors:** (e.g., *"Everything was going fine... until they noticed one tiny detail."*)
2. **Auditory Connectors:** J-cuts (audio of next scene starts 0.5s prior) + impact whooshes on cuts.
3. **Visual Connectors:** Snap zooms, match cuts, and whip-pans.

Read the complete guide in [`docs/viral_story_framework.md`](docs/viral_story_framework.md).

## 🛠️ How to Publish to Your GitHub

1. Clone or initialize this repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial AI Animation Reel Engine release"
   ```
2. Link to your GitHub account:
   ```bash
   git branch -M main
   git remote add origin https://github.com/NimeshDholakiya/ai-animation-reel-engine.git
   git push -u origin main
   ```
3. **Enable GitHub Pages:**
   - Go to **Settings → Pages** in your GitHub repository.
   - Set **Branch** to `main` and folder to `/ (root)`.
   - Your interactive simulator will be live instantly!
